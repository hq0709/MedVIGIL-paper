Reading the comparison
Blue text marks additions; red text marks removals; black text is retained.

The comparison covers manuscript text, not repository scripts or metadata.

Limits of the markup
Figures use the revised artwork; image pixels and graphical labels are not
compared. Math and citation markup are disabled for typesetting stability.
Changes to these objects should be checked against the two source commits.
The clean manuscript and the main/appendix change-scope notes remain the
authoritative current text and scope record. This review PDF is not a claim
that any outstanding experiment or archival requirement has been completed.

Building the supplied review source
From the repository root, run:
  tectonic neurips_2026_changes.tex
It uses the existing neurips_2026.sty, ref.bib, figures/, icons/ and fonts/.
The embedded checklist is already part of neurips_2026_changes.tex.

Comparison generation
The starting comparison used the official CTAN standalone latexdiff-so,
with these options:
  --type=CFONT --math-markup=0 --disable-citation-markup
  --graphics-markup=none
Before running latexdiff, replace the single \input{checklist} in each
revision of neurips_2026.tex with that revision's checklist.tex. The resulting
review source also contains a legend and the R4 table layout repair described
above. The supplied .tex preserves these review-only layout adjustments and
can be compiled directly without rerunning latexdiff.

The public review files contain no private answer sheet, full image mapping,
credentialed gold records or per-probe clinician responses.
